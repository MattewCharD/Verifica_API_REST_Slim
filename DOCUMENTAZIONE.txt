---------------------------------ALUNNI-----------------------------------------


Recuperare tutte le classi: curl http://localhost:8080/classi

Richiesta:
GET    /classi                 ClassiController:index

Risposta
Status code: 200   
[{"id": 1, "sezione":"5A", "anno": 2024},  {"id": 2 , "sezione":"5B", "anno": 2024}]



Vedere solo una classe: curl http://localhost:8080/classi/1

Richiesta:
GET     /classi/1               ClassiController:show

Risposta
Status code: 200   
{"id": 1, "sezione":"5A", "anno": 2024}

Se la classe non è stata trovata:
Status code: 404   
{"msg": "Not Found"}



Creare una classe: curl -X POST http://locahost:8080/classi -H "Content-Type: application/json" -d '{"sezione": "5C", "anno": "2024"}

Richiesta:
POST    /classi               ClassiController:create

Risposta
Status code: 201   
{"msg": "OK"}

se la query non va a buon fine:
Status code: 400   
{"msg": "KO"}



Modificare una classe: curl -X PUT http://locahost:8080/classi/1 -H "Content-Type: application/json" -d '{"sezione": "5C", "anno": "2024"}

Richiesta:
PUT    /classi               ClassiController:update

Risposta
Status code: 201  
{"msg": "OK"}

se la classe non è stata trovata o la query non va a buon fine:
Status code: 400  
{"msg": "KO"}





Eliminare una classe: curl -X DELETE http://locahost:8080/classi/1

Richiesta:
DELETE    /classi/1               ClassiController:destroy

Risposta
Status code: 201  
{"msg": "OK"}

se classe non è trovata o la query non è andata a buon fine:
Status code: 400   
{"msg": "KO"}



---------------------------------Alunni---------------------------------


Recuperare tutti gli alunni da una classe: curl http://localhost:8080/classi/2/alunni

Richiesta:
GET     /classi/2/certificazioni            AlunniController:viewAll

Risposta
Status code: 200   
[{"id": 3, "alunno_id": 2, "titolo": "Certificazione Python", "votazione": 85, "ente": "Coursera"}]

se alunno_id non è trovato:
Status code: 404   
{"msg": "Not Found"}

Filtri (con query Params):
search = ricerca una stringa in titolo e in ente;
sortCol = sceglie la colonna su cui fare il sort;
sort = per decidere se fare il sort ASCendent o DESCendent;




Vedere solo una certificazione: curl http://localhost:8080/alunni/3

Richiesta:
GET     /certificazioni/3               AlunniController:view

Risposta
Status code: 200   
{"id": 3, "alunno_id": 2, "titolo": "Certificazione Python", "votazione": 85, "ente": "Coursera"}

Se certificazione non trovato:
Status code: 404   
{"msg": "Not Found"}






Creare una certificazione per un alunno: curl -X POST http://locahost:8080/alunni/1/certificazioni -H "Content-Type: application/json" -d '{"titolo": "Certificazione Python", "votazione": 85, "ente": "Coursera"}'

Richiesta:
POST    /alunni/1/certificazioni               AlunniController:create

Risposta
Status code: 201   
{"msg": "Created"}

se alunno non trovato:
Status code: 404  
{"msg": "Alunno Not Found"}

se body con parametri mancanti:
Status code: 400   
{"msg": "Missing Params"}



Modificare una certificazione: curl -X PUT http://locahost:8080/certificazioni/1 -H "Content-Type: application/json" -d '{"alunno_id": 2, "titolo": "Certificazione Python", "votazione": 85, "ente": "Coursera"}'

Richiesta:
PUT    /certificazioni/1                   AlunniController:update

Risposta
Status code: 200   
{"msg": "Updated"}

se alunno non trovato:
Status code: 404  
{"msg": "Alunno Not Found"}

se body con parametri mancanti:
Status code: 400   
{"msg": "Missing Params"}
