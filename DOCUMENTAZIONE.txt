---------------------------------ALUNNI-----------------------------------------


Recuperare tutte le classi: curl http://localhost:8080/classi

Richiesta:
GET    /classi                 ClassiController:index

Risposta
Status code: 200   
[{"id": 1, "sezione":"5A", "anno": 2024},  {"id": 2 , "sezione":"5B", "anno": 2024}]



Vedere solo una classe: curl http://localhost:8080/classi/1

Richiesta:
GET     /classi/1               ClassiController:show

Risposta
Status code: 200   
{"id": 1, "sezione":"5A", "anno": 2024}

Se la classe non è stata trovata:
Status code: 400   
{"msg": "Not Found"}



Creare una classe: curl -X POST http://locahost:8080/classi -H "Content-Type: application/json" -d '{"sezione": "5C", "anno": "2024"}

Richiesta:
POST    /classi               ClassiController:create

Risposta
Status code: 201   
{"msg": "OK"}

se la query non va a buon fine:
Status code: 400   
{"msg": "KO"}



Modificare una classe: curl -X PUT http://locahost:8080/classi/1 -H "Content-Type: application/json" -d '{"sezione": "5C", "anno": "2024"}

Richiesta:
PUT    /classi               ClassiController:update

Risposta
Status code: 201  
{"msg": "OK"}

se la classe non è stata trovata o la query non va a buon fine:
Status code: 400  
{"msg": "KO"}





Eliminare una classe: curl -X DELETE http://locahost:8080/classi/1

Richiesta:
DELETE    /classi/1               ClassiController:destroy

Risposta
Status code: 201  
{"msg": "OK"}

se classe non è trovata o la query non è andata a buon fine:
Status code: 400   
{"msg": "KO"}



---------------------------------Alunni---------------------------------


Recuperare tutti gli alunni da una classe: curl http://localhost:8080/classi/1/alunni

Richiesta:
GET     /classi/2/alunni            AlunniController:index

Risposta
Status code: 200   
[{"id": 1, "nome":"Claudio", "Cognome": "Benvenuti"},  {"id": 2 , "nome":"Ivan", "cognome": "Bruno"}]



Vedere solo un alunno: 

Richiesta:
GET     /classi/2/alunni/1                  AlunniController:show

Risposta
Status code: 200   
{"id": 1, "nome":"Claudio", "Cognome": "Benvenuti"}

Se alunno non trovato:
Status code: 404   
{"msg": "Not Found"}


Per creare un alunno

Creare una certificazione per un alunno: curl -X POST http://locahost:8080/alunni/1/certificazioni -H "Content-Type: application/json" -d '{"titolo": "Certificazione Python", "votazione": 85, "ente": "Coursera"}'

Richiesta:
POST    /alunni/1/certificazioni               AlunniController:create

Risposta
Status code: 201  
{"msg": "OK"}

se alunno non trovato:
Status code: 400  
{"msg": "KO"}



Modificare un alunno: curl -X PUT http://localhost:8080/classi/2/alunni/1 -H "Content-Type: application/json" -d '{"alunno_id": 2, "titolo": "Certificazione Python", "votazione": 85, "ente": "Coursera"}'

Richiesta:
PUT    /classi/2/alunni/1                 AlunniController:update

Risposta
Status code: 200   
{"msg": "Updated"}

se alunno non trovato:
Status code: 400  
{"msg": "Alunno Not Found"}



Eliminare un alunno: curl -X DELETE http://localhost:8080/classi/2/alunni/1

Richiesta:
DELETE    /classi/2/alunni/1               AlunniController:destroy

Risposta
Status code: 200   
{"msg": "Deleted"}
